# Landing Page – Café Orvalho

Landing page responsiva de uma cafeteria **fictícia**, feita com **HTML, CSS e JavaScript puro** para praticar layout e interatividade no front-end.

## Funcionalidades

- Layout responsivo (desktop, tablet e celular) com CSS Grid e Flexbox
- Menu "hambúrguer" no mobile
- Cardápio com abas gerado dinamicamente a partir de um objeto JavaScript
- Animações ao rolar a página com `IntersectionObserver`
- Xícara ilustrada e animada somente com CSS
- Validação de e-mail no formulário de newsletter
- Acessibilidade: link "pular para o conteúdo", atributos ARIA, respeito a `prefers-reduced-motion`

## Conceitos praticados

- HTML semântico (`header`, `nav`, `main`, `section`, `article`, `footer`)
- Variáveis CSS, `clamp()`, `min()`, `auto-fit` / `minmax()`
- Media queries e abordagem responsiva
- Manipulação do DOM e eventos
- `IntersectionObserver` e expressões regulares

## Como executar

Basta abrir o arquivo `index.html` no navegador.

> Café Orvalho é uma marca fictícia; depoimentos e endereço são ilustrativos.
